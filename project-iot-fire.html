IoT-Based Fire & Smoke Detection System

An automated fire safety system using an ESP32 microcontroller to analyze real-time sensor data and trigger local and cloud-based alerts.

Nov 2025 — Dec 2025 · El Sewedy University
ESP32Arduino IDEFirebaseBlynk

01 Overview

This system pairs an ESP32 microcontroller with temperature, gas, and flame sensors to detect hazardous conditions in real time and respond automatically — both on-site and remotely.

02 Problem Statement

Fire hazards need to be caught and acted on immediately. A system that only alerts someone standing nearby isn't enough — it also needs to notify people who aren't physically present.

03 Features & Responsibilities

  • Engineered the sensor pipeline: temperature, gas, and flame sensors feeding into the ESP32
  • Programmed the automation logic in Arduino IDE to trigger a buzzer alarm, status LCD, and smoke exhaust fan during hazard states
  • Integrated Firebase to log environmental data to a cloud database
  • Integrated Blynk to broadcast instant mobile emergency notifications

04 Architecture & Technologies

The ESP32 reads sensor data continuously and runs the hazard-detection logic locally for fast response (buzzer, LCD, fan), while also streaming data to Firebase and pushing alerts through Blynk for remote visibility.

05 Lessons Learned

Working across hardware and cloud layers in one project reinforced how much reliability matters at the sensor level — noisy or delayed sensor readings ripple straight through to the alerts people depend on.

06 Future Improvements

  • Add a companion mobile dashboard for historical data trends
  • Support multiple sensor nodes across a building
  • Battery/backup power handling for outages
