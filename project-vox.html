VOX Cinema System

A cinema management and movie booking system covering movie listings, seat reservation, and ticket booking, developed using Python.

My role: GUI / UX Design
PythonDatabaseAuthenticationGUI
View on GitHub ↗

01 Overview

VOX Cinema System is a movie booking and cinema management application that lets users browse movies, select seats, and complete bookings, while giving cinema staff a way to manage listings and reservations.

02 Problem Statement

Manual seat allocation and paper ticketing are slow and error-prone. The system needed to let users see live seat availability and book confidently, without double-booking.

03 Features

  • Movie management — adding and browsing showtimes
  • Interactive seat reservation with real-time availability
  • End-to-end booking flow
  • User authentication
  • Database-backed persistence for bookings and users

04 My Responsibilities

I designed and built the graphical user interface — the movie browsing screens, the seat-selection layout, and the booking flow — focusing on making the seat map clear and the checkout steps simple to follow.

05 Architecture & Technologies

Built in Python with a database backend to store movies, seats, and bookings, and a GUI layer that reflects live seat state so users always see accurate availability.

06 Challenges

Designing a seat map interface that stays readable and usable as theater size and booking state change was the trickiest UX problem — it needed to be glanceable, not cluttered.

07 Lessons Learned

Small interface decisions — like how a "selected" vs "taken" seat is visually distinguished — have an outsized effect on how trustworthy a booking system feels to use.

08 Future Improvements

  • Payment gateway integration
  • Admin dashboard for managing showtimes and pricing
  • Responsive/web version of the booking interface
