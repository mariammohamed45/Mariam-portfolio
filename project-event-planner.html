Event Planner App

A cross-platform mobile application for streamlining event creation, organization, and scheduling.

Apr 2025 — May 2025 · El Sewedy University
FlutterDartFirebaseQR Codes

01 Overview

Event Planner is a cross-platform mobile app built with Flutter and Dart that lets users create, organize, and schedule events with reminders and secure sign-in.

02 Problem Statement

Organizing events across scattered notes, group chats, and calendars is easy to lose track of. The app centralizes event details, reminders, and check-ins in one place.

03 Features & Responsibilities

  • Developed the cross-platform app using Flutter and Dart
  • Integrated Firebase for secure user authentication and real-time data storage
  • Built cloud push notifications and local reminders to keep users engaged
  • Built an intuitive UI featuring dynamic QR code generation, image uploads, and efficient state management

04 Architecture & Technologies

The app is built on Flutter/Dart for a single cross-platform codebase, with Firebase handling authentication, real-time data, and push notifications. State management keeps the UI responsive as event data updates.

05 Lessons Learned

Building the QR code and notification features taught me how much small UX touches — like an instant local reminder versus a delayed push notification — shape whether users trust an app to keep them on schedule.

06 Future Improvements

  • Shared/collaborative event planning for groups
  • Calendar app integration (Google Calendar sync)
  • Offline support for viewing event details without connectivity
