AI-Driven Forest Fire & Smoke Detection System

A deep learning image classification system that categorizes environmental scenes into fire, smoke, and non-fire states, benchmarking a custom CNN against a MobileNetV2 transfer-learning model.

Custom CNN + MobileNetV2 · Data pipeline · Evaluation
PythonTensorFlowKerasOpenCVNumPyGoogle Colab
View on GitHub ↗

01 Overview

This project uses a Convolutional Neural Network to classify images into three categories — Fire, Smoke, and Non-Fire — trained on a real-world forest fire and smoke image dataset from Kaggle, with results validated against a MobileNetV2 transfer-learning baseline.

02 Problem Statement

Early, automated detection of fire and smoke in image or video feeds can support faster response in environments like forests and industrial sites, where manual monitoring is slow or impractical.

03 Features

  • Three-class image classification: Fire / Smoke / Non-Fire
  • Custom lightweight CNN trained from scratch
  • MobileNetV2 transfer-learning model for comparison
  • Data augmentation and class weighting to address dataset imbalance
  • Model evaluation via confusion matrices and classification reports
  • Early stopping, model checkpointing, and ReduceLROnPlateau for stable training

04 My Responsibilities

I collected, cleaned, and organized the fire/smoke/non-fire image dataset and prepared it for training. I also built and trained both the custom CNN and the MobileNetV2 transfer-learning model, applied data augmentation and class weighting to correct for class imbalance, and evaluated both models using confusion matrices and classification reports.

05 Architecture & Technologies

Images were resized to 64×64 and fed into two parallel pipelines: a custom CNN built from scratch, and MobileNetV2 fine-tuned via transfer learning. Both were trained in Google Colab with TensorFlow/Keras, using early stopping and checkpointing to avoid overfitting.

06 Challenges

The dataset had an uneven number of examples per class, which biased early models toward the majority class. Data augmentation and class weighting were needed to get balanced, trustworthy performance across all three categories.

07 Lessons Learned

Comparing a model built from scratch against a transfer-learning baseline made the trade-offs concrete: MobileNetV2 converged faster with less data, while the custom CNN gave more control over architecture at the cost of longer training.

08 Future Improvements

  • Deploy the model for real-time video stream inference
  • Expand the dataset with more diverse lighting and terrain conditions
  • Package the model behind a lightweight API or edge-device deployment
